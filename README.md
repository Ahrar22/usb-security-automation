# cross-platform USB Photo Backup Tool
An automated Python script designed to monitor system ports, detect connect USB drives, and automatically backup image files from the local drive to the external storage. This tool is built with a security and automation mindset.

## Features
* **Cross-Plateform Support:** work seemlessly on Windows, macOS, and Linux.
* **Automated Detection:** Continously monitors hardware ports for external USB drive connections.
* **Smart Backup:** Scans specific directories (like Drive C on Windows) and transfer all image formats securely to the USB drive.

## Tech Stack
* Python 3.x
* Built-in OS and hardware Monitoring Librarries

## How to Run
1. Clone this repository.
2. Run the script: 'python usb-backup.py'
3. Insert a USB drive to see the autmationin action
